# meu-node-supabase

Projeto da aula de Aplicação Web II desenvolvido em sala com auxílio do professor.

Tecnologias utilizadas: NodeJs, Supabase, Express

## Rotas

| Método | Rota          | O que faz             |
| ------ | ------------- | --------------------- |
| GET    | `/alunos`     | Lista os alunos       |
| GET    | `/alunos/:ra` | Busca um aluno        |
| POST   | `/alunos`     | Cadastra um aluno     |
| PUT    | `/alunos/:ra` | Atualiza um aluno     |
| DELETE | `/alunos/:ra` | Apaga um aluno        |
